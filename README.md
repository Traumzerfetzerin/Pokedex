# 🔥 Pokédex

A modern and responsive Pokédex web application built with **HTML**, **CSS**, **JavaScript**, **Bootstrap**, and the **PokéAPI**.

## 📋 Features

* Display Pokémon cards with images and detailed information
* Search Pokémon by name
* Load additional Pokémon dynamically
* Detailed Pokémon view in a modal/dialog
* Navigation between Pokémon entries
* Pokémon types, abilities, height, weight, and base experience
* Base stats overview
* Evolution chain display
* Pokémon habitat information
* Pokémon cry/audio playback
* Responsive design for desktop and mobile devices
* Dark mode interface

## 🚀 Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Bootstrap 5
* PokéAPI

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Pokedex.git
```

2. Navigate to the project folder:

```bash
cd Pokedex
```

3. Open `index.html` in your preferred web browser.

## 🌐 API

This project uses the free Pokémon API:

* [PokéAPI](https://pokeapi.co/?utm_source=chatgpt.com)

## 🎮 How to Use

1. Open the application in your browser.
2. Browse the available Pokémon cards.
3. Use the search bar to find a Pokémon by name.
4. Click on a Pokémon card to view detailed information.
5. Navigate through Pokémon using the previous and next buttons.
6. Click **Load More** to fetch additional Pokémon.
